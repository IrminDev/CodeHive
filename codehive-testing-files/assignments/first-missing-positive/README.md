# First Missing Positive

Self-contained assignment fixture for testing hidden-test failures. The task asks
for the smallest positive integer absent from an array.

## Folder structure

```text
first-missing-positive/
├── README.md
├── reference.cpp
├── inputs/
│   ├── 01-sample.in
│   ├── 02-unsorted-negative.in
│   ├── 03-duplicates.in
│   └── 04-consecutive.in
└── verdicts/
    ├── README.md
    └── wa/main.cpp
```

## Manual assignment fields

| Field | Value |
| --- | --- |
| Group | Any owned, active, non-archived group |
| Title | First Missing Positive |
| Description | Given an array of integers, print the smallest positive integer that does not appear in the array. |
| Constraints | `1 <= N <= 100000`; `-1000000000 <= A[i] <= 1000000000` |
| Reference language | C++ |
| Allowed languages | C++, Java, Python, C |
| Time limit | `1000 ms` |
| Memory limit | `128 MB` |
| Comparator | Exact match |
| Publishing | Publish immediately |

## Input and output

Input:

```text
N
A1 A2 ... AN
```

Output:

```text
smallest missing positive integer
```

## Hidden-test failure scenario

Use `verdicts/wa/main.cpp` as student submission. It assumes the input is already
sorted and checks values by position. It returns `1` for hidden case 2, while the
reference returns `2`.

Expected definitive result:

| Test case | Result |
| --- | --- |
| 1 | AC |
| 2 | WA (`got 1`, `expected 2`) |
| 3 | AC |
| 4 | AC |

The fixture uses valid input within constraints. No malformed-input behavior is
required, so verdicts remain comparable across languages.
