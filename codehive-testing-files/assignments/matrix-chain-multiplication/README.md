## Manual assignment fields

| Field | Value |
| --- | --- |
| Group | Any owned, active, non-archived group |
| Title | Matrix Chain Multiplication |
| Description | Given `N` matrices where matrix `i` has dimensions `D[i-1] x D[i]`, find minimum scalar multiplications needed to multiply entire chain. Matrix order cannot change, but parenthesization may change. |
| Constraints | `1 <= N <= 165`; dimensions line contains `N + 1` integers; `1 <= D[i] <= 1000`; answer fits signed 64-bit integer |
| Hints | Let `dp[i][j]` be minimum cost for matrices `i..j`; try every final split `k`; fill intervals from shortest to longest |
| Tags | `dynamic programming`, `interval DP`, `matrix chain`, `O(N^3)` |
| Reference language | C++ |
| Allowed languages | C++, Java, Python, C |
| Time limit | `10000 ms` |
| Memory limit | `128 MB` |
| Maximum points | `100` |
| Comparator | Exact match |
| Publishing | Publish immediately |
| Launch date | Empty |
| Due date | Optional future date |
| Close date | Optional; empty or later than due date |

## Input and output

Input:

```text
N
D0 D1 ... DN
```

Output:

```text
minimum scalar multiplication count
```

Example:

```text
Input
4
40 20 30 10 30

Output
26000
```

Explanation: `(A1 × (A2 × A3)) × A4` gives minimum cost `26000`.
