# Topological Sort

Self-contained assignment fixture for ordering the vertices of a directed graph.
The required answer is the lexicographically smallest topological ordering. If
the graph contains a directed cycle, print `IMPOSSIBLE`.

## Input and output

Input:

```text
N M
u1 v1
u2 v2
...
uM vM
```

Each edge `u v` means that vertex `u` must appear before vertex `v`.

Output one line:

- The lexicographically smallest topological ordering, with vertices separated by single spaces; or
- `IMPOSSIBLE` if no topological ordering exists.

Example:

```text
Input
6 6
6 3
5 3
5 4
4 2
3 1
2 1

Output
5 4 2 6 3 1
```
