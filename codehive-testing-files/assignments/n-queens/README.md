# N-Queens

Self-contained assignment fixture for counting valid placements of `N` queens on
an `N × N` chessboard. No two queens may share a row, column, or diagonal.

## Manual assignment fields

| Field | Value |
| --- | --- |
| Group | Any owned, active, non-archived group |
| Title | N-Queens |
| Description | Given `N`, print number of ways to place `N` queens on an `N × N` board so no two queens attack each other. Queens may not share a row, column, or diagonal. |
| Constraints | `1 <= N <= 14`; answer fits signed 64-bit integer |
| Hints | Place one queen per row. Track used columns and both diagonal directions. A bitmask makes each recursive state compact. |
| Tags | `backtracking`, `bitmasks`, `recursion`, `combinatorics` |
| Reference language | C++ |
| Allowed languages | C++, Java, Python, C |
| Time limit | `5000 ms` (covers optimized Python at `N = 14`) |
| Memory limit | `128 MB` |
| Maximum points | `100` |
| Comparator | Exact match |
| Publishing | Publish immediately |

## Input and output

Input:

```text
N
```

Output:

```text
number of valid N-Queens placements
```

Example:

```text
Input
4

Output
2
```

The two valid placements for `N = 4` are reflections of each other.
